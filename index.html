  • Quick check: \(\text{logsig}(n)+\text{logsig}(-n)=1\), and \(\tanh(n)=2\,\text{logsig}(2n)-1\).

Q2. Bias, nonlinearity and the learning process

[12 marks]
  1. A neuron outputs \(y=\dfrac{1}{1+e^{-(x+b)}}\). Find \(b\) so that \(y=0.8\) when \(x=1\). Where is the sigmoid midpoint now, and which way has the curve shifted?
  2. Show that a two-layer network with linear activations in both layers reduces to a single-layer linear model. What does this tell you about activation functions?
  3. Explain the effect of a learning rate \(\alpha\) that is too large or too small.
  4. Classify as supervised or unsupervised: (i) grouping customers by purchase history with no labels; (ii) predicting house price from labelled sales data.
Show worked answer
(a) Solve for the bias
\[ 0.8=\frac{1}{1+e^{-(1+b)}}\ \Rightarrow\ e^{-(1+b)}=\tfrac{1}{0.8}-1=0.25\ \Rightarrow\ 1+b=\ln 4=1.3863 \] \(b\approx 0.386\). The midpoint (\(y=0.5\)) is where \(x+b=0\), so \(x=-0.386\). A positive bias shifts the curve left.
(b) Linear layers collapse
\[ \mathbf{a}^2=W^2(W^1\mathbf{p}+\mathbf{b}^1)+\mathbf{b}^2=\underbrace{(W^2W^1)}_{W}\mathbf{p}+\underbrace{(W^2\mathbf{b}^1+\mathbf{b}^2)}_{\mathbf{b}} \] This is one linear layer \(W\mathbf{p}+\mathbf{b}\). Adding more linear layers adds no power. A nonlinear activation is what lets a network model curved decision boundaries (for example XOR).
(c) Learning rate
If \(\alpha\) is too large, the updates overshoot the minimum, so learning oscillates or diverges. If \(\alpha\) is too small, convergence is very slow and costly. Choosing it is a trade-off between stability and speed.
(d) Learning paradigm
(i) Unsupervised: there are no targets and the task is clustering. (ii) Supervised: there are input–target pairs and the task is regression.
Important notes
  • The bias moves the curve horizontally. Its midpoint is at \(x=-b\): \(b>0\) shifts left, \(b<0\) shifts right.
  • The training cycle is: forward pass → prediction → loss → backward pass → weight update.
  • The threshold \(\theta\) can be absorbed into the bias (\(b=-\theta\)).
Tips & tricks
  • For any logistic equation, find \(e^{-n}=\frac1y-1\) first, then take logs.
  • Memory aid: positive bias means the neuron is “eager” and fires earlier, so the curve moves left.

Important notes
  • ADALINE (Widrow & Hoff, 1959) minimises \(E=\tfrac12(t-y)^2\) by gradient descent. It is also called the delta rule, LMS or Widrow–Hoff rule.

  • The theoretical stability bound is \(0<\alpha<2/\lambda_{max}(R)\), where \(R=\frac1P\sum \mathbf{x}\mathbf{x}^T\) (or \(1/\lambda_{max}\) if the update has a factor 2).
Tips & tricks
  • Compute \(\eta e\) once per row, then add \(\eta e\cdot x_i\). For bipolar inputs you only flip its sign.
  • Remember: perceptron uses (t − thresholded y), ADALINE uses (t − linear y). The update formula is the same, but y is different.

Q6. MADALINE training with MR-I (and MR-II)

[15 marks]

A MADALINE has two hidden ADALINEs \(Z_1,Z_2\) and a fixed OR output unit \(v_1=v_2=b_y=\tfrac12\). It uses the bipolar step \(f(x)=1\) if \(x\ge0\), else \(-1\), and \(\alpha=0.5\).

  1. With \(w_{11}=0.05,\ w_{21}=0.2,\ b_1=0.3,\ w_{12}=0.1,\ w_{22}=0.2,\ b_2=0.15\), present \(\mathbf{x}=(1,1),\ t=-1\). Apply one MR-I step.
  2. Another network has \(w_{11}=0.2,\ w_{21}=0.5,\ b_1=0,\ w_{12}=0.3,\ w_{22}=0.2,\ b_2=-0.2\). Present \(\mathbf{x}=(1,-1),\ t=+1\) and apply one MR-I step. Verify that the new output is correct.
  3. Explain why the output weights are \(\tfrac12\) and how MR-II differs from MR-I.
Show worked answer
(a) Forward pass
\(z_{in1}=0.3+0.05+0.2=0.55\), \(z_{in2}=0.15+0.1+0.2=0.45\), so \(z_1=z_2=1\).
\(y_{in}=0.5+0.5+0.5=1.5\), so \(y=1\neq t=-1\).
Because \(t=-1\), update every hidden unit with positive net input (both here), using \(w_{ij}\leftarrow w_{ij}+\alpha(-1-z_{inj})x_i\): \[ Z_1:\ \alpha(-1-0.55)=-0.775\Rightarrow b_1=-0.475,\ w_{11}=-0.725,\ w_{21}=-0.575 \] \[ Z_2:\ \alpha(-1-0.45)=-0.725\Rightarrow b_2=-0.575,\ w_{12}=-0.625,\ w_{22}=-0.525 \]
(b) Forward pass
\(z_{in1}=0+0.2-0.5=-0.3\), \(z_{in2}=-0.2+0.3-0.2=-0.1\), so \(z_1=z_2=-1\) and \(y_{in}=0.5-0.5-0.5=-0.5\), giving \(y=-1\neq t=+1\).
Because \(t=+1\), update only the unit whose net input is closest to 0, which is \(Z_2\) (\(|-0.1|<|-0.3|\)): \[ \alpha(1-z_{in2})=0.5(1.1)=0.55\ \Rightarrow\ b_2=0.35,\ w_{12}=0.3+0.55=0.85,\ w_{22}=0.2-0.55=-0.35 \] Check: \(z_{in2}=0.35+0.85+0.35=1.55\), so \(z_2=1\), \(y_{in}=0.5-0.5+0.5=0.5\), and \(y=+1=t\) ✓
(c) Theory
With \(v=b_y=\tfrac12\), \(y_{in}=\tfrac12(1+z_1+z_2)\), which is negative only when both \(z\)'s are \(-1\). So \(Y\) acts as an OR unit. MR-I trains only the hidden weights and assumes an OR output. MR-II adjusts all weights and does not assume OR. It trial-flips the output of hidden units whose net input is near 0 (e.g. \(|z_{in}|<0.25\)), starting with the one closest to 0. If the flip reduces the error, it applies the delta rule with the flipped value as the target.
Important notes
  • MR-I rules: \(t=+1\) → update the one unit closest to 0, towards target \(+1\). \(t=-1\) → update all units with \(z_{in}>0\), towards target \(-1\).
  • The update uses the net input \(z_{in}\), not the thresholded \(z\). It is the delta rule with target ±1.
  • A MADALINE combines several linear boundaries, giving a nonlinear overall decision. This is how it can solve XOR.
Tips & tricks
  • Compute the factor \(\alpha(\pm1-z_{inj})\) once per unit, then add it times each \(x_i\) (and once to the bias).
  • “Closest to zero” means the smallest \(|z_{in}|\). That unit needs the least change to flip.

Q7. Performance surface and the LMS algorithm

[18 marks]

An ADALINE with no bias is trained on \(\mathbf{p}_1=(1,-1,-1)^T,\ t_1=-1\) and \(\mathbf{p}_2=(1,1,-1)^T,\ t_2=1\). The two pairs are equally likely.

  1. Find \(c=E[t^2]\), \(\mathbf{h}=E[t\mathbf{p}]\) and \(R=E[\mathbf{p}\mathbf{p}^T]\), and write \(F(\mathbf{x})\).
  2. Find the eigenvalues of the Hessian and classify the stationary point(s).
  3. Find the maximum stable learning rate for \(W(k+1)=W(k)+2\alpha e(k)\mathbf{p}^T(k)\).
  4. Starting from \(W(0)=\mathbf{0}\) with \(\alpha=0.2\), perform two LMS iterations (\(\mathbf{p}_1\) then \(\mathbf{p}_2\)). Where will \(W\) converge?
Show worked answer
(a) Statistics
\(c=\tfrac12(1+1)=1\). \(\ \mathbf{h}=\tfrac12[(-1)\mathbf{p}_1+(1)\mathbf{p}_2]=\tfrac12[(-1,1,1)+(1,1,-1)]=(0,1,0)^T\). \[ R=\tfrac12(\mathbf{p}_1\mathbf{p}_1^T+\mathbf{p}_2\mathbf{p}_2^T)=\begin{pmatrix}1&0&-1\\0&1&0\\-1&0&1\end{pmatrix},\qquad F(\mathbf{x})=c-2\mathbf{x}^T\mathbf{h}+\mathbf{x}^TR\mathbf{x}=1-2x_2+\mathbf{x}^TR\mathbf{x} \]
(b) Hessian \(A=2R\)
\(\det(R-\lambda I)=(1-\lambda)[(1-\lambda)^2-1]=0\), so \(\lambda(R)=0,1,2\) and \(\lambda(A)=0,2,4\).
All eigenvalues are \(\ge0\) and one is zero, so this is a weak minimum. \(R\) is singular, so \(\mathbf{x}^*=R^{-1}\mathbf{h}\) does not exist. Solving \(R\mathbf{x}=\mathbf{h}\) gives \(x_1-x_3=0,\ x_2=1\): a whole line of minima \((c,1,c)\), each with zero error.
(c) Stability
\(\alpha<\dfrac{2}{\lambda_{max}(A)}=\dfrac24\), so \(\alpha<0.5\) (equivalently \(1/\lambda_{max}(R)=1/2\)).
(d) Two iterations
\(k=0\): \(a=W\mathbf{p}_1=0\), \(e=-1-0=-1\), \(W(1)=\mathbf{0}+2(0.2)(-1)(1,-1,-1)=(-0.4,\ 0.4,\ 0.4)\).
\(k=1\): \(a=-0.4+0.4-0.4=-0.4\), \(e=1-(-0.4)=1.4\), \(W(2)=(-0.4,0.4,0.4)+0.56(1,1,-1)=\) \((0.16,\ 0.96,\ -0.16)\).
Every update is a combination of \(\mathbf{p}_1,\mathbf{p}_2\), which both satisfy \(x_1=-x_3\). The only minimum on that subspace with \(x_1=x_3\) is \(W^*=(0,1,0)\), the minimum-norm solution.
Important notes
  • The MSE of an ADALINE is always quadratic, and its Hessian \(2R\) is positive (semi)definite, so there are never local maxima or saddles. You get either a unique global minimum, a weak minimum, or no minimum.
  • Widrow and Hoff's key idea was to replace \(E[e^2]\) by the instantaneous \(e^2(k)\), giving the gradient \(-2e(k)\mathbf{z}(k)\).
  • Positive definite ⇔ all eigenvalues > 0 ⇔ all leading principal minors > 0.
Tips & tricks
  • Check which convention the question uses: a factor 2 in the update gives \(\alpha<1/\lambda_{max}(R)\), and none gives \(\alpha<2/\lambda_{max}(R)\). State the convention in your answer.
  • For \(3\times3\) eigenvalues, expand along a row with zeros (here row 2) to factor out \((1-\lambda)\) immediately.
  • A quick check of R: its diagonal is the mean-square value of each input component (here all 1).

  2. For “If it rains, the ground is wet”, write the converse, inverse and contrapositive. Which are equivalent to the original?
  3. Write XOR in terms of ∧, ∨ and negation, and give its set-theoretic meaning.
  4. \(X=\{1,2,3,4\},\ A=\{2,3\},\ Y=\{a,b,c\},\ B=\{b,c\}\). Build the relation for IF A THEN B, and infer \(B'\) for \(A'=\{2\}\) and for \(A'=\{3,4\}\).
Show worked answer
(a) Use \(P\Rightarrow Q\equiv\bar P\vee Q\)
\[ \overline{P\wedge(\bar P\vee Q)}\vee Q=\bar P\vee\overline{(\bar P\vee Q)}\vee Q=\bar P\vee(P\wedge\bar Q)\vee Q \] \[ =\big[(\bar P\vee P)\wedge(\bar P\vee\bar Q)\big]\vee Q=\bar P\vee\bar Q\vee Q=\bar P\vee1=1 \] It is true for every truth assignment, so it is a tautology ✓.
(b) Related forms
Converse (\(Q\Rightarrow P\)): if the ground is wet, it rained.
Inverse (\(\bar P\Rightarrow\bar Q\)): if it does not rain, the ground is not wet.
Contrapositive (\(\bar Q\Rightarrow\bar P\)): if the ground is not wet, it did not rain.
The contrapositive ≡ original, and the converse ≡ inverse. The converse is not equivalent to the original.
(c) XOR
\(P\oplus Q=(P\wedge\bar Q)\vee(\bar P\wedge Q)\). In set terms this is the symmetric difference \((A\setminus B)\cup(B\setminus A)\). XNOR is its negation and equals \(P\Leftrightarrow Q\).
(d) \(R=(A\times B)\cup(\bar A\times Y)\)
Rows for \(x\in A\) copy \(\chi_B\). Rows for \(x\notin A\) are all 1. \[ R=\begin{array}{c|ccc}&a&b&c\\\hline1&1&1&1\\2&0&1&1\\3&0&1&1\\4&1&1&1\end{array} \] \(A'=\{2\}\subseteq A\): \(B'=A'\circ R=\) row 2 \(=\{b,c\}=B\) ✓ (modus ponens recovers B).
\(A'=\{3,4\}\): \(B'=\max(\text{row 3},\text{row 4})=\{a,b,c\}=\) Y. The input overlaps \(\bar A\), and with no ELSE clause anything in Y is possible.
Important notes
  • \(P\Rightarrow Q\) is false only when P is true and Q is false. When P is false the implication is vacuously true.
  • Implication in set form is \(\bar A\cup B\), with truth value \(\max(1-T(P),T(Q))\).
  • Indirect proof: show that \(P_1\wedge\dots\wedge P_n\wedge\bar Q\) is a contradiction.
  • Duality: swapping ∧↔∨ and 0↔1 turns a valid identity into another valid identity.
Tips & tricks
  • To prove a tautology, convert every ⇒ to \(\bar P\vee Q\), push negations in with De Morgan, and aim for \(X\vee\bar X\).
  • If the algebra stalls, a 4- or 8-row truth table is always accepted and is hard to get wrong.
  • For IF A THEN B ELSE C, use \(R=(A\times B)\cup(\bar A\times C)\). Rows outside A copy C instead of all 1s.

Q22. Sugeno (TSK) and Tsukamoto inference

[16 marks]
  1. TSK (lecture Ex 7.8): \(x=4,\ y=2\). R1: IF \(A_1\) and \(B_1\) THEN \(z_1=3x+2y+4\). R2: IF \(A_2\) and \(B_2\) THEN \(z_2=2x+5y+12\). Grades: \(\mu_{A_1}=0.6,\ \mu_{B_1}=0.8,\ \mu_{A_2}=0.5,\ \mu_{B_2}=0.4\). Find \(z^*\) using the min T-norm, then using the product T-norm.
  2. Tsukamoto (lecture Ex 7.9): same tip inputs and rules as Q21, with \(\mu_{High}(y)=y/20\) and \(\mu_{Low}(y)=(20-y)/20\). Find \(y^*\).
  3. Explain why ANFIS uses a hybrid learning rule.
Show worked answer
(a) TSK
Firing (min): \(w_1=\min(0.6,0.8)=0.6\), \(w_2=\min(0.5,0.4)=0.4\).
Rule outputs: \(z_1=12+4+4=20\), \(z_2=8+10+12=30\).
\(z^*=\frac{0.6(20)+0.4(30)}{0.6+0.4}=\) 24
With product: \(w_1=0.48,\ w_2=0.20\), so \(z^*=\frac{9.6+6}{0.68}=22.94\).
(b) Tsukamoto
\(\alpha_1=\max(0.8333,0.8)=0.8333\), \(\alpha_2=\min(0.1667,0.2)=0.1667\).
Invert the monotonic consequents: \(y_1=20\alpha_1=16.67\), \(y_2=20(1-\alpha_2)=16.67\).
\(y^*=\frac{0.8333(16.67)+0.1667(16.67)}{1}=\) 16.67 % (compare Mamdani 13.72 %).
(c) ANFIS hybrid learning
The output is linear in the consequent parameters \(p_{ij}\), so the forward pass solves them in one step by (recursive) least squares, which gives the global optimum in that subspace. The premise MF parameters are nonlinear, so the backward pass tunes them by gradient descent. Splitting the work this way converges much faster than pure gradient descent.
Important notes
  • TSK consequents are crisp functions: zero-order \(f_i=c_i\), first-order \(f_i=p_{i0}+\sum p_{ij}x_j\). The output is a normalised weighted average, so no defuzzification is needed.
  • Tsukamoto consequents must be strictly monotonic, so \(\mu^{-1}(\alpha)\) is unique.
  • Comparison: Mamdani for expert/control knowledge, TSK for data-driven modelling and optimisation, Tsukamoto for special cases.
  • ANFIS layers: 1 fuzzify, 2 firing strength, 3 normalise, 4 linear consequent, 5 sum.
Tips & tricks
  • Always state which T-norm you used. Min and product give different answers (24 vs 22.94), and both are accepted if declared.
  • If the firing strengths already sum to 1, the weighted average is just \(\sum w_iz_i\).

Q23. Rule decomposition, aggregation and T/S-norms

[14 marks]
  1. The grades are \(\mu_{A_1}=0.3,\ \mu_{A_2}=0.8,\ \mu_{A_3}=0.6\). Find the firing strength of “IF \(x_1\) is \(A_1\) and \(x_2\) is \(A_2\) or \(x_3\) is \(A_3\)” using standard precedence, then using the grouping \(A_1\wedge(A_2\vee A_3)\).
  2. At some \(y\), two clipped rule outputs give \(0.4\) and \(0.7\). Give the conjunctive and disjunctive aggregated values.
  3. For \(a=0.7,\ b=0.6\), evaluate the drastic, Łukasiewicz, product and min T-norms; the max, algebraic-sum, bounded-sum and drastic S-norms; and the Yager T-norm with \(p=2\). Arrange them in the norm hierarchy.
  4. Explain the difference between shallow and deep knowledge with an example.
Show worked answer
(a) Decomposition (AND → min, OR → max, AND binds first)
\((A_1\wedge A_2)\vee A_3=\max(\min(0.3,0.8),0.6)=\max(0.3,0.6)=\) 0.6
\(A_1\wedge(A_2\vee A_3)=\min(0.3,\max(0.8,0.6))=\min(0.3,0.8)=0.3\). The grouping changes the answer.
(b) Aggregation
Conjunctive (all rules must hold) \(=\min(0.4,0.7)=0.4\). Disjunctive (at least one rule) \(=\max=0.7\). Mamdani systems use disjunctive aggregation.
(c) Norms
T-norms: drastic \(=0\) (neither input is 1). Łukasiewicz \(\max(0,a+b-1)=0.3\). Product \(0.42\). Min \(0.6\).
Yager \(p=2\): \(1-\min(1,\sqrt{0.3^2+0.4^2})=1-0.5=0.5\).
S-norms: max \(0.7\). Algebraic sum \(a+b-ab=0.88\). Bounded sum \(\min(1,1.3)=1\). Drastic \(=1\) (neither input is 0).
Hierarchy: \(0\le0.3\le0.42\le0.5\le0.6\ \big|\ 0.7\le0.88\le1\le1\) ✓
Duality check: \(S(a,b)=1-T(1-a,1-b)=1-(0.3)(0.4)=0.88\) ✓ (product ↔ algebraic sum).
(d) Knowledge
Shallow knowledge is a rule of thumb that maps observations directly to conclusions, for example “IF temperature is high THEN open the cooling valve more”. Deep knowledge is the underlying model, for example the plant's energy balance, which explains why and can predict new situations. A fuzzy rule base keeps the shallow rule form but becomes an explicit mathematical model that interpolates between rules.
Important notes
  • A T-norm needs a boundary (\(T(x,1)=x\)), monotonicity, commutativity and associativity. An S-norm is the same with \(S(x,0)=x\).
  • Every T-norm lies between drastic and min. Every S-norm lies between max and drastic sum. Averaging operators (OWA, generalised mean) lie between min and max.
  • Fuzzy complements satisfy \(N(0)=1,\ N(1)=0\) and are decreasing. Families: Sugeno \(\frac{1-a}{1+sa}\), Yager \((1-a^w)^{1/w}\).
Tips & tricks
  • Draw the expression tree for mixed rules and evaluate bottom-up. That works for any nesting.
  • Memorise the hierarchy chain (A.3). Many MCQ/short questions are just “order these”.
  • The duality \(S(a,b)=1-T(1-a,1-b)\) lets you derive any S-norm from its T-norm instead of memorising both.
